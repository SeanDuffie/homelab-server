# homelab-server
A series of dockerfiles that will be run on my private compute server at home. These will serve a range of self-hosting purposes including:
- Local AI Hosting: [Ollama](https://ollama.com/download)
  - Allow Local AI to search the internet: [SearXNG](https://github.com/searxng/searxng)
- E2EE Discord Messaging Alternative: [Matrix](https://matrix.org/foundation/about/) - [Conduit](https://conduit.rs/)
- Dedicated Servers for various games: [Minecraft](https://github.com/itzg/docker-minecraft-server), TODO: [Palworld](https://github.com/pocketpairjp/palworld-dedicated-server-docker), etc.
- Locally hosted GitHub alternative: [Forgejo](https://forgejo.org/releases/)
